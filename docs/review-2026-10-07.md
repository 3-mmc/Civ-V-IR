# Formable Nations review — 7 October 2026

Reviewed the tracked SQL, Lua, UI, localisation, packaging and tests against the pinned Vox Populi 5.4.6 engine source. The mod builds, and its original 15 offline scenarios passed before the review; those scenarios did not cover the failures below. No Civ V session was launched, so this is not an in-game acceptance test.

## Fixed

| Area | Failure and correction |
| --- | --- |
| Fragmentation | `AcquireCity` deletes the old engine city. Province processing retained follower city objects and accessed them after transfer. It now snapshots plots and fetches the current city before processing it. |
| Membership | Humans could join organisations while at war with the leader or another member. The shared eligibility check now rejects this, and the panel uses the same check. Founding also excludes candidates at war with an already selected candidate. |
| Referendums | An AI that left could be recruited on the next leader turn, resetting its cohesion. Departures now impose a game-speed-scaled 30-turn cooldown, including direct joining and founding. |
| Leadership | If the last major left an organisation with two city-states, leadership stayed with the departed major. The organisation now dissolves if no major successor exists. |
| Open borders | Founding the EU granted borders, then dissolving its predecessor immediately revoked them. Removing membership now preserves grants supplied by another active organisation. |
| Union progression | A union with already-owned claims had no cohesion bonds and could never deepen. It now checks that the union's claims still hold and its prerequisite tenure has elapsed. Remaining independent partners still require sustained integration. |
| Absorption | A marriage could satisfy an ABSORB claim without paying for or transferring the city-state. Marriage now follows the absorption path. |
| Great Britain | The Celtic-major route incorrectly accepted continuing vassalage for the State stage. It now requires the Celtic original capital to be owned, consistently with other major-civ absorption claims. |
| Crises | Several partners could open simultaneous crises and bypass the stated union-wide cooldown. Opening and cooldown are now shared across the union. |
| Calls to arms | The unprocessed declaration queue existed only in Lua memory and vanished on reload. It is now saved. Concurrent calls against different teams no longer overwrite each other, and obsolete calls cannot restart a settled war. Legacy single-call saves are migrated when read. |
| Military transfer | Recreating absorbed units discarded experience, promotions and damage. Conversion now preserves these attributes. Civilian disbanding remains the existing mod rule. |
| Advanced starts | An organisation founded on game turn zero was treated as inactive. Its active marker now encodes turn plus one. |

Regression coverage lives in `mods/FormableNations/tests/regressions.lua`, called by the existing harness. It includes a transfer mock that invalidates old city access rather than silently retaining the old object.

## Missing or simplified features

These are design/roadmap gaps, not claims that the corresponding systems were completed by this review:

- Consensual unions between major players, junior autonomy investment and multiplayer synchronisation.
- Partner-initiated petitions/loyalty pledges. Union privileges currently charge Gold; they do not share the union policy bonus with the partner.
- Union equilibrium does not yet directly model vassal tax rates, local wartime losses or ideology mismatch; it uses the implemented terms in `FN_Cohesion.lua`.
- OPEC pays Gold per Oil. Shared oil monopolies and production quotas are absent.
- A Zollverein organisation/formation route and the proposed science consortium are absent. The German Empire has a Zollverein-themed trade bonus instead.
- Supranational redistribution budgets, coordinated World Congress votes, voluntary exit notice periods and post-exit trade penalties are absent. The existing low-cohesion referendum and new rejoin cooldown are separate mechanics.
- Independent diplomatic open-border deals are not separately tracked from organisation grants. Overlapping organisation grants are now handled, but leaving can still revoke a separately negotiated deal.
- Diplomatic penalties for absorbing a protected city-state and per-player custom city-state diplomacy names still require engine work.

The design document now distinguishes several of these intentions from implemented behaviour. Adding the missing systems would be a further feature-development task.

## Validation and remaining checks

- Lua 5.1 parsing, XML syntax, SQL/reference validation, English/German keys and placeholders, settings validation and original plus regression scenarios pass through `build.py`.
- SQL was also executed against an in-memory copy of the local Civ5DebugDatabase, removing its older FN data first. The game database itself was not changed.
- The generated package is under `mods/FormableNations/build/(9) Formable Nations/` in the relocated repository. Subsequently deployed on 2026-10-07 at 21:49 UTC: all 22 package files and 25 city-state sound entries verified, with the installed VP DLL unchanged. The previous installation is backed up under `../backups/formable-nations/20261007T214940Z/`.
- Still required in Civ V: start a new game, form/absorb/deepen a union, exercise fragmentation and calls to arms across a save/load, inspect the overlay and both languages, and check Lua.log/Database.log. Unit conversion and UI layout in particular still require engine-level confirmation.
