# Vox Populi mod shortlist

Research checked on 2026-09-10 for a full VP 5.4.6 foundation. These are candidates to evaluate, not a tested combination or an installation manifest. None of the optional mods below has been downloaded or enabled.

Quest Log's author also publishes Trade Scanner, which searches available deals and can execute selected trades. It deserves a separate decision: it changes the interaction with diplomacy and is more than a passive information panel. Do not bundle it automatically just because the two share a thread.

More Unique Components (the older 3rd/4th component addition) is described as integrated into VP by its author in the More Wonders thread. Check the pinned base before importing older Workshop components with overlapping effects.

## Curation sources

Use the [VP Mods Repository](https://forums.civfanatics.com/forums/mods-repository.549/) and individual authors' release threads as discovery sources. The curator's [compatibility notice](https://forums.civfanatics.com/threads/mod-compatibility-with-latest-version.701787/) explains that base-game changes can invalidate mods and that abandoned incompatible mods may move to the archive. Remaining in the active forum does not establish compatibility with our exact package.

Prefer focused features, inspectable source, clear version requirements, and evidence that the AI understands new mechanics. Recent activity alone does not establish quality. Larger content packs should earn their memory and maintenance costs through features the user actually wants.
